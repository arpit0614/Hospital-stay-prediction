# Hospital Stay Duration Prediction (Healthcare Analytics)

## 📌 Project Overview
An operational data analytics project designed to optimize hospital bed management and resource allocation. The machine learning model estimates the length of stay (in days) for admitted patients based on case details and demographics.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn, Seaborn, Matplotlib
* **Environment:** Jupyter Notebook

## 📊 Exploratory Data Analysis (EDA)
* Conducted intensive EDA to identify key operational bottlenecks such as admission type impacts and department loads.
* Visualized correlation matrices and feature importance rankings using Seaborn.

## 🧠 Modeling Approach
* Implemented  **Logistic regression** **XGBoost classifire** **Random Forest classifire** and **Decision Trees** to handle non-linear combinations of patient attributes.
* Optimized tree depth and minimum sample splits via Cross-Validation.

## 🚀 Key Results
* Effectively mapped out top predictors influencing long-stay patients, allowing hospital operations to reduce bed vacancy time.
* Achieved an Accuracy 43.91%
